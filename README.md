## О проекте

Финансовый помощник с элементами искусственного интеллекта.

Предполагаемый стек:

* Flutter Web (Frontend)
* Spring Boot (Backend)
* PostgreSQL (База данных)
* AI-интеграция для финансовых рекомендаций

Исходный код и материалы проекта будут приложены отдельно.
